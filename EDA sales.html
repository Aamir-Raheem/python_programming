def clean_column(col, strategy='mean'):
    df[col] = df[col].apply(lambda x: np.nan if str(x).strip().upper() in ['UNKNOWN', 'ERROR'] else x)
    if strategy == 'mean':
        df[col] = pd.to_numeric(df[col], errors='coerce')
        df[col].fillna(df[col].mean(), inplace=True)
    elif strategy == 'mode':
        df[col].fillna(df[col].mode()[0], inplace=True)
 
# so instead of cleaning the columns one by one, we can simply use this function

📊 Conclusion¶

This project offered a comprehensive look into customer transactions. Some key insights include:

  • February had the highest sales — further investigation is needed to understand the spike.
  • Digital Wallets are the most preferred payment method, especially for takeaway orders.
  • Juice leads in quantity sold, while Coffee dominates in total revenue.

By combining data cleaning and Python-based visualizations, I was able to transform raw data into actionable insights. This project demonstrates how even a small dataset can reveal important business patterns when analyzed the right way.
