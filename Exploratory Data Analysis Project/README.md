# 🛒 Exploratory Data Analysis (EDA) on Sales Dataset

This project demonstrates a complete Exploratory Data Analysis (EDA) process using a fictional sales dataset. The goal is to uncover patterns, trends, and insights from transactional sales data using Python libraries and visualizations.

## 📁 Project Structure

- `EDA sales.html`: The exported HTML report containing all data cleaning steps and visualizations.
- `README.md`: You’re reading it!

## 🔧 Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook (for report generation)

## 🔍 Key Objectives

- Perform initial data exploration and cleaning
- Identify missing or inconsistent entries
- Generate meaningful aggregations and summaries
- Create visualizations to interpret key business insights

## 📊 Visualizations Included

- Distribution of total sales
- Most purchased items
- Location-wise revenue trends
- Payment method breakdown
- Product preference across locations (grouped bar chart)

## 🧼 Data Cleaning Steps

- Handled missing values and inconsistent entries
- Standardized categorical values
- Verified data types and conversions

## 🧠 Insights

Some insights gathered through this EDA:

- Identified top-selling items
- Analyzed payment method popularity
- Evaluated customer preference by region
- Visualized the concentration of sales by item and quantity

## 📌 How to View

To view the analysis:

1. Download the `EDA sales.html` file.
2. Open it in any modern web browser.
